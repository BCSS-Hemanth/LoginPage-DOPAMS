# DOPAMS — Drug Offences Monitoring & Analysis System

A modern, high-performance forensic login portal built for the **Drug Offences Monitoring and Analysis System (DOPAMS)** featuring an animated forensic laboratory environment.

## 🌟 Key Features

- **Translucent Glassmorphism Interface**: Minimalist, high-contrast login card featuring the official Telangana Police Eagle Force emblem integrated as an authentic background watermark.
- **Cinematic Atmospheric Animations**:
  - **Fluid Kelvin-Helmholtz Vapor**: Organic blue chemical vapor emerging directly from the Erlenmeyer flask opening with wave turbulence.
  - **Realistic Dropper Gravity Physics**: Periodic amber chemical droplet beading at the glass pipette tip, falling with gravitational acceleration, and creating an impact surface ripple.
  - **Effervescent Micro-Bubbles**: Dynamic buoyant chemical micro-bubbles rising through the flask liquid.
  - **High-Tech Atmospheric Dust**: Floating luminous blue particles drifting continuously with gentle Brownian motion.
  - **Surveillance Telemetry**: CRT scanline sweep and blinking CCTV tally status indicator.
  - **3D Mouse Parallax**: Depth-reactive movement shifting ambient reflections and particles.
- **Responsive Coordinate Projection**: Mathematical coordinate locking algorithm ensuring all particles, smoke plumes, and liquid pulses remain precisely aligned with laboratory apparatus across any monitor resolution or aspect ratio.
- **Accessibility & Motion Control**: Native motion toggle and prefers-reduced-motion media query support.

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler & Server**: [Vite 8](https://vite.dev/)
- **Styling**: Vanilla CSS3 (Custom Glassmorphism Design System)
- **Canvas / Physics**: HTML5 Canvas 2D API (`requestAnimationFrame`, particle dynamics)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (Rajdhani, Inter, JetBrains Mono)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/BCSS-Hemanth/LoginPage-DOPAMS.git
   cd LoginPage-DOPAMS
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/`.

### Production Build

To build the project for production:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
